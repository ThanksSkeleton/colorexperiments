HSL vs OKLCH vs Experimental FP-HK Complement

Select an sRGB base color. The page compares a normal HSL complement, an OKLCH complement, and an experimental Fairchild–Pirrotta-style Helmholtz–Kohlrausch lightness-matched complement. An × over a swatch means the computed target color is outside sRGB before clipping, so the displayed color is only a clipped approximation.

Examples

Prototype definition

HSL complement: rotate HSL hue by 180°, keep HSL saturation and lightness. OKLCH complement: rotate OKLCH hue by 180°, keep OKLCH L and C. FP-HK complement: rotate OKLCH hue by 180°, keep OKLCH C, then solve for OKLCH L whose Fairchild–Pirrotta equivalent achromatic lightness approximately matches the base color.

This is not a canonical “HK color space.” It is a deliberately small browser experiment for testing whether an H-K-informed lightness correction visibly changes the OKLCH complement result.
