Reason / note
Move over the plane.

Munsell Value here means only the Value coordinate, not full Munsell hue/chroma notation. This project displays Munsell Value only at V1 and above. It is estimated by converting displayed OKLCH → XYZ → CIELAB D50 → luminance Y, then numerically inverting the Newhall–Nickerson–Judd 1943 Munsell Value luminance polynomial. The plane overlay marks approximate integer Value contours with 50% white pixels.

If the requested OKLCH color is outside sRGB, the toy reports the Munsell Value for the chroma-clipped display color.
