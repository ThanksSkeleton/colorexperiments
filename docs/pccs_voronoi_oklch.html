PCCS Voronoi Regions in OKLCH

A deliberately approximate translation of the 14 PCCS tone centers into fixed-hue OKLCH lightness–chroma slices. Each Munsell hue name is used only as a label for an approximate OKLCH hue angle; no Munsell color conversion is performed.

Coordinate bridge: OKLCH lightness is approximately related to PCCS lightness through the standard Munsell Value–luminance polynomial. Chroma uses one approximate OKLCH-C-per-Munsell-Chroma ratio for each hue, summarized from the project’s in-sRGB samples. The Paper 2001 equations then supply PCCS saturation and the hue-dependent t = l − a(h)s transform. Classification is corrected Euclidean nearest-center distance in the PCCS (s, t) plane.

Each region is colored with its translated tone center’s OKLCH color at the selected hue. Portions outside sRGB are shown at 10% opacity over a checkerboard. The gamut test uses the plotted point’s native OKLCH scales: L = 0…1 and C = 0…0.4. These are exploratory fitted projections, not measured correspondences between PCCS and OKLCH.

Modified PCCS: Below the DP centerpoint in lightness but above it in chroma, only DP is eligible. Below DP in both dimensions, DP/D/G/DK/DKG are eligible; below DK in both, DK/G/DKG; and below DKG in both, only DKG. More-specific bottom-left rules take precedence. Thresholds are recalculated for each hue.
