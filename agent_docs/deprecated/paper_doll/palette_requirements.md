# Additional Palette Requirements

- **Off-black:** Matches off-white except that the base costume color is desaturated dark.
- **Pure Black:** Matches Pure White using black instead of white.
- **Hair/Eyes Monochrome:** Has separate `WBW` and `BWB` variants describing the assignment of white and black to Primary Costume, Secondary Costume, and Accent.
- **Power Monochrome:** Has separate `WBW` and `BWB` variants using the same role-assignment pattern.
- **Split Complementary:** Has separate White and Black variants.
