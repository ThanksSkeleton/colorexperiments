# Terminology

- **Paper Doll:** A layered figure used as a rudimentary preview of a color scheme applied to a character.
- **Base Color:** The single primary color from which hue geometry builds palettes.
- **Important Color:** The base color or a color produced through hue geometry with the same chroma and lightness.
- **Color Role:** The part of a character to which a color is applied, such as eyes or costume.
- **Color Package:** A set of colors related to an important color by hue but varied in chroma or lightness. Its shape and size depend on the color role.
- **Complete Palette:** All colors associated with the character roles.
- **Paper Doll Palette:** The important colors assigned directly to the paper-doll roles.

The interface uses a single base OKLCH color, selectable palette previews, a paper-doll display driven by the active palette, detailed color information, and expandable constant controls.
