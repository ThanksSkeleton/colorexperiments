# Later Paper Doll Goals

1. Integrate the power symbol into each paper doll as a normal image layer.
2. Make drawing a doll from a supplied palette reusable and extensible to additional dolls.
3. Add a semi-fixed school-uniform treatment while retaining palette-derived hair, eye, and power colors.
4. Hide constants and export details behind expandable controls by default.
5. Provide reusable `generate_palette(inputColor)` and `paintdoll(dollType, palette)` APIs.
6. Keep palette generation independent of the application and DOM-rendering layer.
